The finding

A genome-scale map that knows which direction is up.

Rank the knockdowns by causal effect size and the biggest hits are the entire TCR-signalling module — recovered unsupervised. Add a per-cell direction-of-effect axis and the interpretation flips: those top effects all point down (knockdown cripples the cell). The drug signal lives in the sparse quadrant above the line.

Each point is one gene knockdown across 2.64 M cells. Teal = required machinery (knockdown impairs effector function); amber = candidate brakes (knockdown enhances it). Marker shape encodes donor consistency. Rendered from the tracked ranked_perturbations.csv by figure_causal_map.py.

Why two axes

Magnitude tells you how much. Only the sign tells you which way.

↑ direction > 0 — a brake

Knockdown pushes cells toward the effector program. Removing the gene enhances function — the therapeutic quadrant. Recovers CD5, DGKA, CBLB.

↓ direction < 0 — machinery

Knockdown pushes cells away from the effector program. The gene is required for function — a large effect in the wrong direction. The entire TCR module lands here.

01

Causal effect size

Power-equalized energy distance with a permutation E-test on the scVI donor-integrated latent — ranks by causal magnitude, not p-values (which inflate with cell count).

02

Direction of effect

Per cell, an effector program minus a dysfunction program, aggregated per perturbation × donor with a per-donor sign-agreement flag. Computed on all 2.64 M cells in ~40 s.

03

Gated & honest

Viability catches toxic knockdowns; the authors' knockdown-efficiency sidecar confirms on-target; donor consistency is reported, not hidden.

Validation

It recovers ground truth — in both axes.

Unsupervised, the largest causal effects are the canonical TCR proximal-signalling module: ZAP70, CD3D/E/G, CD247, PLCG1, LAT, LCP2, VAV1, ITK. The direction axis then flags every one of them as machinery — and it agrees across both donors, every time.

That two-way agreement with known biology is the internal control: a map that gets the machinery right in sign is a map you can trust to point at the brakes.

The therapeutic quadrant

The brakes the map surfaces — reported honestly.

Knockdowns that raise the effector program are the drug-relevant class. The quadrant recovers real immune-brake biology. With two donors, the machinery axis is unanimous but the brake signals are modest — so this is a prioritized shortlist for the full four-donor cohort, not a finished target claim.

A convergent network layer (public STRING interactome + Open Targets genetics) independently highlights IL2RB/CD122. The direction axis explains it: its knockdown is lethal — required machinery for the pro-survival IL-2 signal — which is exactly why the drug is an IL-2/CD122 agonist (aldesleukin, N-803), not an inhibitor.

Reproducible by design

One command. Fixed seeds. MIT.

Every artifact carries its exact code, environment, and a plain-language trail; a reviewer agent checks each claim against what actually ran — it caught a real statistical bug before it reached a figure. The pure-logic core tests run anywhere; the genome-scale axis regenerates on a GPU workstation.
